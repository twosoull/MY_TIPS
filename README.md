# 마이꿀팁

내가 직접 경험해서 얻은 작은 노하우를 빠르게 기록하는 모바일 우선 웹앱입니다.

## 실행

별도 설치나 빌드가 필요하지 않습니다. `index.html`을 브라우저에서 열면 바로 사용할 수 있습니다.

## GitHub Pages 배포

1. 이 폴더의 파일을 GitHub 저장소에 업로드합니다.
2. 저장소의 **Settings → Pages**로 이동합니다.
3. **Deploy from a branch**를 선택하고, `main` 브랜치의 `/ (root)`를 지정합니다.
4. 표시되는 주소를 iPhone Safari에서 연 뒤 **공유 → 홈 화면에 추가**를 선택합니다.

데이터는 해당 브라우저의 `localStorage`에 저장됩니다. 브라우저 데이터를 삭제하면 기록도 사라지므로 중요한 내용은 별도로 백업해 주세요.
